# Сборка UniLauncher на домашнем Windows

## Что понадобится
- Windows 10/11 x64 на компьютере для сборки.
- .NET 10 SDK x64: https://dotnet.microsoft.com/download/dotnet/10.0
- Интернет на время первой сборки для восстановления компонентов .NET.
- Visual Studio не обязательна. Если она уже установлена, можно использовать её терминал.

## Сборка в один запуск
1. Распакуйте весь исходный ZIP в локальную папку, например `C:\\Projects\\UniLauncher`.
2. Установите .NET 10 SDK x64.
3. Дважды щёлкните `BUILD.bat`.
4. Дождитесь сообщения `BUILD SUCCESSFUL`.

Скрипт проверит Windows и .NET SDK, восстановит проект, соберёт автономную Windows x64 версию и создаст ZIP-пакет.

## Где искать результат
- EXE: `dist\\UniLauncher\\UniLauncher.exe`
- Папка для переноса на компьютер БГУ: `dist\\UniLauncher\\`
- ZIP для переноса: `dist\\UniLauncher_v1.0_RC_win-x64.zip`

Приложение публикуется как self-contained single-file: .NET runtime включён в приложение. Отдельно устанавливать .NET на компьютерах БГУ не требуется.

## Первый запуск дома
1. Запустите `dist\\UniLauncher\\UniLauncher.exe`.
2. Проверьте, что появляется тёмное окно и доступны вкладки Workspace, Applications, Browser & Websites, Profiles и Diagnostics.
3. Нажмите Run diagnostics.
4. Добавьте Notepad (обычно `C:\\Windows\\System32\\notepad.exe`) во вкладке Applications и проверьте запуск.
5. Добавьте публичный сайт и проверьте Chrome/Yandex, если браузер установлен.
6. Создайте тестовый профиль и проверьте его применение.
7. Проверьте создание локальных файлов в `%LOCALAPPDATA%\\UniLauncher`.

## Перенос в БГУ
Скопируйте всю папку `dist\\UniLauncher` на сетевой диск, а не только EXE. Запустите EXE с сетевого диска.
Сетевой каталог должен разрешать создание и изменение `settings.json`, `profiles.json` и `UniLauncher.log`.

## Если сборка завершилась ошибкой
Не пытайтесь наугад менять код. Скопируйте весь текст ошибки из окна BUILD.bat и отправьте его. Важно прислать первую ошибку компиляции, а не только итоговое `Build failed`.

## Ограничения текущего кандидата
- Это Release Candidate, а не сертифицированный релиз.
- Desktop Organizer остаётся экспериментальным: сопоставляет значки по индексам.
- Применение Alt+Shift и Print Screen зависит от версии Windows и политик БГУ.
- Профили и настройки используют простую стратегию выбора более новой копии; одновременное редактирование на нескольких ПК не поддерживается.
- Cookies, пароли и токены браузеров не копируются; используется обычный локальный профиль браузера.


## Альтернатива: облачная сборка через GitHub Actions
Если на домашнем компьютере не хочется устанавливать .NET SDK:
1. Создайте **приватный** GitHub-репозиторий.
2. Загрузите в него содержимое исходного проекта.
3. Откройте вкладку **Actions**.
4. Выберите workflow **Build UniLauncher for Windows** и нажмите **Run workflow** (или дождитесь автоматической сборки после push).
5. После успешного выполнения откройте запуск workflow и скачайте артефакт `UniLauncher-v1.0-RC-win-x64`.

GitHub Actions использует Windows runner и собирает автономный Windows x64 пакет. Артефакт доступен 14 дней. Не загружайте в репозиторий пароли, cookies, токены или реальные пользовательские настройки.
