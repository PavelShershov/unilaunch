# UniLauncher — краткое руководство пользователя

## Первый запуск
1. Запустите `UniLauncher.exe` из папки на университетском сетевом диске.
2. На вкладке Workspace выберите нужные модули.
3. Укажите путь к файлу обоев, если используете Wallpaper Manager.
4. Укажите пути к Chrome и Яндекс Браузеру, если программа не обнаружила их автоматически.
5. Нажмите Save selection.

## Приложения
На вкладке Applications нажмите Add EXE / shortcut и выберите `.exe` или `.lnk`.
В столбце Run отметьте приложения, которые должны запускаться при применении набора.
Нажмите Save list. Прямые EXE, которые уже работают и доступны для проверки, повторно не запускаются.

## Сайты и браузеры
На вкладке Browser & Websites:
1. Выберите Chrome, Yandex или Both.
2. Добавьте сайты через Add website.
3. Включите галочками нужные сайты.
4. Укажите порядок вкладок в столбце Order.
5. Нажмите Save list.
6. Используйте Test Chrome / Test Yandex для отдельной проверки.

Браузер запускается с обычным локальным профилем. UniLauncher не извлекает и не переносит cookies, пароли или токены авторизации. Если университет очищает профиль браузера при выходе, авторизация может потребовать повторного входа.

## Профили
На вкладке Profiles:
- Save current as new — сохранить текущие галочки модулей, выбранные приложения и сайты как новый набор.
- Apply profile — применить сохранённый набор.
- Update selected — перезаписать выбранный набор текущими настройками.
- Delete selected — удалить выбранный набор.

Профили хранятся в `profiles.json` рядом с программой и в локальной резервной копии.

## Рабочий стол
На вкладке Workspace нажмите Remember desktop layout, чтобы сохранить текущие координаты, затем включите Desktop Organizer для применения.
Текущий механизм экспериментальный: позиции сопоставляются по индексам значков. Если состав или порядок значков изменился, результат может быть неправильным. Сначала тестируйте на неважных значках. При отличающемся разрешении восстановление отменяется.

## Диагностика и файлы
На вкладке Diagnostics нажмите Run diagnostics. Журнал `UniLauncher.log` находится рядом с EXE. Локальная резервная копия находится в `%LOCALAPPDATA%\\UniLauncher`. Если приложение аварийно завершилось, проверьте `fatal.log` в этой локальной папке.

## Облачное хранение
Настройки и профили записываются рядом с EXE на сетевом диске, а также копируются в LocalAppData. Если сеть недоступна, программа может работать с локальной копией. При следующем запуске выбирается копия настроек с более поздней отметкой времени.
Не запускайте UniLauncher одновременно на двух компьютерах с одним и тем же сетевым каталогом: синхронизация параллельных изменений и автоматическое объединение конфликтов пока не реализованы.

## Ограничения
UniLauncher работает с правами текущего пользователя и не обходит групповые политики. Администраторские права могут требоваться для действий, которые университет запретил обычному пользователю. В таком случае модуль должен сообщить об отказе, а не пытаться обходить ограничение.
